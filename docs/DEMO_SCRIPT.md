# Demo script

1. Start with an unfamiliar partner question and submit it manually.
2. Select `NO`; the local stance voice should start immediately.
3. Select a visible reason chip and let the deterministic preview speak.
4. On a second prompt, choose `MY OWN REASON`, type with the letter groups, and choose `SAY EXACTLY` or approve an expansion.
5. Open Lab to show flags, provider badges, the 40-target test, and CSV export.
6. Optional: choose `head` or `gaze`, click Start camera pointer, and use the same large targets.
7. If camera, network, or provider access fails, use mouse/manual input and browser speech. No provider failure blocks the AAC path.
